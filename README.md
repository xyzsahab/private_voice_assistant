# AI Task Assistant

A voice-controlled desktop assistant built using Python that can perform basic automation tasks, answer queries, open applications/websites, and interact through speech.

This project started as an experiment with speech recognition and gradually evolved into a personal assistant capable of handling simple day-to-day computer tasks through voice commands.

The assistant can:
- Listen to voice commands
- Speak responses back to the user
- Open websites and applications
- Perform small automation tasks
- Tell jokes and provide information
- Trigger keyboard shortcuts

## Features

- Speech recognition using microphone input
- Text-to-speech responses
- Website launching
- Voice typing shortcut
- Wikipedia search support
- Basic desktop automation
- Fun conversational responses
- Keyboard shortcut automation using PyAutoGUI

## Technologies Used

- Python
- SpeechRecognition
- pyttsx3
- PyAutoGUI
- pygame
- Wikipedia API

## Example Commands

- "Open YouTube"
- "What is the time"
- "Tell me a joke"
- "Open Google"
- "Voice typing"
- "Search Wikipedia"
